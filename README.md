
# Jacinthe : Projet de robot à deux roues



## Matériel
- Raspberry Pico 2W
- SSD1306 écran OLED
- Batterie NiMH 6V 2800mAh
- 2 Moteurs DC JGA25-370 6V 280RPM
- TB6612FNG driver de moteurs DC
- LM2596 Buck 6V -> 5V
- MPU6050 Gyroscope Accéléromètre

## Logiciel
- Micropython, HTML
- Librairie ssd1306 appartenant à **stlehmann**
